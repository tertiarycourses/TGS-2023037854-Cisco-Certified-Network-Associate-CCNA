# Lab 07 - Security, ACLs, Port Security, and Wireless

## Objectives

- Secure device management.
- Configure standard and extended ACLs.
- Configure port security.
- Review wireless architecture and security.

## Steps

1. Review management access configuration.
2. Confirm SSH is enabled.
3. Configure strong local credentials.
4. Create a standard ACL to permit management only from an admin subnet.
5. Apply the ACL to VTY lines.
6. Create an extended ACL to permit one service and deny another.
7. Apply the ACL in the correct direction and interface.
8. Test allowed and denied traffic.
9. Configure port security on an access port.
10. Set maximum MAC address count.
11. Set violation action.
12. Verify with `show port-security interface`.
13. Review AP, WLC, SSID, CAPWAP, WPA2, and WPA3 concepts.
14. Record how wireless security differs from wired access control.

## Validation

- Management ACL permits intended source only.
- Extended ACL behaves as planned.
- Port security status is verified.
- Wireless architecture notes are complete.

## Review Questions

1. Where should standard ACLs be placed?
2. Where should extended ACLs be placed?
3. What problem does port security solve?
4. What is the role of a wireless LAN controller?
