# Lab 01 - Network Models, Addressing, and Subnetting

## Objectives

- Compare OSI and TCP/IP models.
- Explain encapsulation.
- Create an IPv4 subnet plan.
- Recognize IPv6 address types.

## Steps

1. Draw the OSI model.
2. Draw the TCP/IP model.
3. Map Ethernet, IP, TCP, UDP, HTTP, DNS, and DHCP to the correct layers.
4. Explain how data is encapsulated from application to Ethernet frame.
5. Use a /24 network assigned by your trainer.
6. Divide the network into at least four equal subnets.
7. Record network address, usable host range, broadcast address, and prefix.
8. Build a simple topology with two PCs and one switch.
9. Configure same-subnet IPv4 addresses.
10. Test reachability with `ping`.
11. Change one host to the wrong subnet and observe the failure.
12. Review IPv6 global unicast, link-local, multicast, and loopback examples.

## Validation

- Subnet table is correct.
- Same-subnet hosts can ping.
- Wrong-subnet failure is explained.
- IPv6 address examples are classified correctly.

## Review Questions

1. What does encapsulation mean?
2. Why does a host need a default gateway?
3. What is the difference between network address and broadcast address?
4. What is a link-local IPv6 address used for?
