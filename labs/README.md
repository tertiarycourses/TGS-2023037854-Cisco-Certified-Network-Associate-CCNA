## Lab Rules

1. Save each topology before making major changes.
2. Record every verification command and result.
3. Use `show` commands before changing configuration.
4. Save working configurations at the end of each lab.
5. Troubleshoot symptoms from Layer 1 upward unless the issue clearly points elsewhere.
